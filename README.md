# Smol calculator

It does math, yes!

Features:
- Addition!
- Substraction!
- Multiplying!
- Division!
- And maybe more??

## Project definition
Basic calculator app, with commandline interface. Coded with C++ as an exercise to learn the language. The app will try to demonstrate what an actual calculator does with its input. This will also work as an exerice to understand basic compiler functionality and design. 

## MVP
- Commandline interface
- Additive and multiplicative calculations
- Translates given expression into Reverse Polish Notation and from there into expression tree
- Calculation will be conducted only one atomic formula at a time

## Future ideas
- More advanced calculations
- Ability to spot incorrect syntax
- Calculation history

## Program layout
- main
    - interface
    - parser/compiler
    - eval

No generative AI is or will be used in any shape or form in this project.
